プライバシーポリシー・利用規約

最終更新：2026年11月2日

うたスコア（以下「本アプリ」）は、個人が作った非公式のWebアプリです。YouTube・Googleとは関係ありません。

プライバシーポリシー

本アプリが扱う情報

  • マイクの音声：歌声の音程や音量を調べるために、端末の中でその場で処理します。録音・保存・送信はしません。保存するのは音程・音量・時刻の数字だけです。
  • 画面共有で取り込む映像・音（「画面の音程バーを使う」「動画の音から作る」を使ったときだけ）：音程バーの位置やメロディの音程を読み取るために、端末の中でその場で処理します。録画・録音・保存・送信はしません。保存するのは音程と時刻の数字だけです。
  • 端末への保存：曲ごとの設定（ガイド、ずれ、キー、歌詞）、採点履歴、設定、デバッグ記録（直近5回分）、同意した日時を、ブラウザの localStorage に保存します。これらはサーバーに送りません。ブラウザのサイトデータを消すと削除できます（デバッグ記録は「設定」から削除できます）。
  • 書き出したファイル：「書き出し」で作るJSONファイルはあなたの端末に保存されるだけで、本アプリが受け取ることはありません。

YouTube・Googleによる情報の扱い

本アプリは YouTube API サービス（YouTube 埋め込みプレイヤー / IFrame Player API）を使って動画を再生します。動画の再生にあたって、YouTube・Google が Cookie などを使って情報を扱うことがあります。詳しくは Googleプライバシーポリシー をご覧ください。

その他

  • 本アプリ自体は、アクセス解析・広告・独自のCookieを使っていません。
  • 本アプリは GitHub Pages で配信しています。配信にともなうアクセス記録は GitHub が扱います（GitHubのプライバシーステートメント）。
  • お問い合わせは GitHub の Issues へお願いします。

  3. 「画面の音程バーを使う」「動画の音から作る」は実験的な機能で、個人での利用を前提にしています。
