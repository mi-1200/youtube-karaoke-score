# うたスコア（YouTubeカラオケ採点）

YouTubeのカラオケ動画を公式プレイヤーで再生しながらマイクで歌い、音程・リズム・抑揚などを採点するWebアプリです。ビルド不要の静的サイト（`index.html` と `core.js`）で、GitHub Pagesで公開します。

## できること

- YouTubeのURLを入れて再生（IFrame Player API。音声の抽出やダウンロードはしません）
- マイクの音程をリアルタイムに検出して、音程バーに歌声の線を表示
- 採点（100点満点、小数点以下3桁）
  - **ガイドあり採点**：音程・安定性・リズム・抑揚・ビブラート・ロングトーン
  - **ガイドなし採点**：どの曲でも、音階への収まり・安定性・抑揚などで採点
- ガイドメロディの用意
  - MIDIファイルを読み込み、歌メロのトラックを選ぶ
  - 「お手本を録る」：一度歌って（または原曲を流して）録った音程をガイドにする
  - 開始のずれ（秒）とキー（半音）で動画に合わせる。オクターブ違いは自動で許容
- 歌詞（LRC形式）の同期表示と、再生しながらタップで時刻を付ける機能
- 曲ごとのデータと採点履歴をブラウザに保存。JSONで書き出し・読み込み

マイクの音声は端末の中だけで処理し、録音・送信はしません。

## 使い方

1. 公開URLを開く（マイクを使うためHTTPSが必要です）
2. カラオケ動画のURLを入れて「読み込む」
3. 「マイクON」→「採点スタート」。イヤホンで伴奏を聴くと採点が正確になります
4. 歌声の線が音程バーより遅れて見えるときは、「設定」の遅延補正を大きくします

## 開発

```sh
python3 -m http.server 8000   # http://localhost:8000 で確認
node --test test/             # 採点ロジックのテスト
```

`main` に push すると GitHub Actions がテストを実行して Pages に公開します（リポジトリの Settings → Pages → Source を「GitHub Actions」にしてください）。
